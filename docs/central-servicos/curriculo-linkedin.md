## LinkedIn — seção de projeto

### Central de Serviços de TI

Desenvolvi e coloquei em produção uma aplicação web para organizar chamados, tarefas internas e rotinas da equipe de TI.

O projeto foi construído com Java 21, Spring Boot, Spring Security, JPA/Hibernate, Thymeleaf, SQL Server e Flyway. Além do fluxo de atendimento, implementei SLA com calendário comercial e pausas, autorização por perfil, portal público, trilha de auditoria, anexos protegidos, quadros Kanban, relatórios e monitoramento de armazenamento.

Também cuidei da parte operacional: Docker Compose, Apache como proxy, scripts PowerShell, backup, configuração externa, instalador Windows com NSIS e pipeline de testes no GitHub Actions.

O principal aprendizado foi tratar a aplicação como um produto em operação, não apenas como código: consistência transacional, segurança no backend, evolução do banco, diagnóstico e recuperação precisaram funcionar juntos.

Por confidencialidade, as demonstrações usam somente dados fictícios e a identidade Empresa Demonstração. Não publico métricas que ainda não foram formalmente coletadas.
