Um resumo sobre mim

Atuo com desenvolvimento de software e curso Engenharia de Software. Minha experiência nasceu de problemas reais de operação: aplicações internas, integração com banco de dados, automação e implantação em ambiente corporativo.

Meu principal estudo de caso é uma Central de Serviços de TI em Java e Spring Boot que desenvolvi e coloquei em produção. O projeto reúne workflow, SLA, controle de acesso, auditoria, testes e uma entrega reproduzível com Docker.

Busco oportunidades de backend Java, especialmente em bancos, fintechs e empresas que desenvolvem para o setor financeiro.
